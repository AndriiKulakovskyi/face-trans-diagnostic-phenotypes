# FACE-ATLAS — technical report (LaTeX source)

The technical report for the FACE-ATLAS project:
**A Transdiagnostic Latent-axis Stratification of Severe Mental Illness**
(bipolar disorder · schizophrenia · depression). The report is one continuous argument in chapters — the
certified nine-dimension **measurement map**, its **stratification** into a transdiagnostic continuum, the
**temporal coherence** of both, the **prognostic** value of the durable axes, and the **treatment** boundary.

## Build

```bash
make            # regenerate figures (python3 make_figures.py) THEN build the PDF (pdflatex ×2)
make figures    # just regenerate the data-driven figures from committed aggregate CSVs
make pdf        # just build the PDF (assumes figures exist)
```

Toolchain: **pdflatex** + **python3/matplotlib** (for the figures). `faceatlas.sty` depends only on packages
in a TeX Live *basic* install (no `tcolorbox`/`titlesec`/non-standard fonts) — coloured callout boxes and all
mechanism diagrams are built from `tikz`, body font is Latin Modern. Figures are generated by
`make_figures.py` from committed aggregate CSVs (`reports/*.csv`, `docs/figures/empirical_atlas.csv`,
`configs/`) — **no per-patient data** is ever read.

## Structure

                      \discoveryflow, \structuregateflow, \archetypesimplex)
make_figures.py       generates the measurement-map data-driven PNGs in figures/ from aggregate CSVs
                      (stratification figures m2_*.png are reused from docs/figures/, generated by scripts/2x)
references.tex        bibliography (manual thebibliography)
sections/

  02_data.tex           data foundation, no-imputation pipeline, observed-cell grid, coverage
  03_model.tex          candidate ontology (9 eligible), soft priors, bifactor/ESEM, mixed likelihoods
  04_estimation.tex     staged continuation, Gaussian marginal = FIML, Woodbury mechanism, compute
  05_results.tex        the NINE-dimension map, prior→posterior atlas, biology⊥G, Φ, adjudication
  06_validation.tex     confirmation, certification, robustness, invariance, dual-block PPC

  m2_strata.tex         strata: structure gate, continuum verdict, 8 archetypes, severity spine, DSM-5 head-to-head
  m3_temporal.tex       temporal coherence: longitudinal invariance, trait/state, spine-vs-corner
  m4_prognosis.tex      prognosis: errors-in-variables incremental value, the archetype atlas, course-dependence
  m5_treatment.tex      treatment: overlap gate, propensity, doubly-robust moderation, the earned boundary
  07_engineering.tex    repository, config-first design, tests, the two fixed bugs, reproducibility
  08_roadmap.tex        future directions (refinements + the studies needed to reach clinical utility)
  09_limitations.tex    limitations and open problems

(File-name prefixes `01..10` are cosmetic; section numbers come from `\section` order in `FACE-ATLAS.tex`,
where `scoring.tex` and the `m2`–`m5` chapters are `\input` in reading order between validation and
engineering.)

## Conventions

The chapters are top-level `\section`s of one continuous argument; cross-references to them read as
"Chapter~N". The reusable building blocks are the callout environments (`keyresult`, `definitionbox`,
`invariantbox`, `methodsbox`, `caveatbox`, `openbox`), the scientific status pills (`\certified`,
`\provisional`, `\rejected` — these mark a finding's *evidential* standing, not project status), the
`\programstrip` pipeline diagram, and the TikZ mechanism macros. Note: status pills and TikZ contain
catcode-sensitive material and must **not** be placed inside section titles (a moving argument) — put them at
the start of the body text instead.

## Provenance

Every number is drawn from the project's committed reports (`reports/`) and findings docs
(`docs/M1_FINDINGS.md`, `docs/ADJUDICATION.md`, `docs/STRATA_FINDINGS.md`, `docs/TEMPORAL_FINDINGS.md`,
`docs/PROGNOSIS_FINDINGS.md`, `docs/TREATMENT_FINDINGS.md`), and is reproducible from the numbered pipeline
(`scripts/01_build_data.py` → `04_fit.py` → the confirmation, invariance, certification, robustness, scoring,
PPC, stratification, temporal, prognosis, and treatment scripts). No per-patient data appear in the report or
its figures.
