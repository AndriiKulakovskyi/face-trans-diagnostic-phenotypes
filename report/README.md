# FACE-ATLAS — technical report (LaTeX source)

The technical report for the FACE-ATLAS project:
**A Transdiagnostic Latent-axis Stratification of Severe Mental Illness**
(bipolar disorder · schizophrenia · depression). The report is one continuous argument organized around
**three pillars**: **(I) dimensional analysis** — the nine-dimension measurement map and why a dimensional
reading beats the categorical default; **(II) archetypes** — reading the map as a continuum through four
extreme phenotypes; and **(III) operating in the latent space** — the payoff (temporal coherence, prognosis,
treatment boundary) and forward potential. The pillars are advanced by five dependent tests (exist · organize ·
persist · predict · guide treatment).

## Build

```bash
make            # regenerate figures (python3 make_figures.py) THEN build the PDF (pdflatex ×2)
make figures    # just regenerate the data-driven figures from committed aggregate CSVs
make pdf        # just build the PDF (assumes figures exist)
```

Toolchain: **pdflatex** + **python3/matplotlib** (for the figures). `faceatlas.sty` depends only on packages
in a TeX Live *basic* install (no `tcolorbox`/`titlesec`/non-standard fonts) — coloured callout boxes and all
mechanism diagrams are built from `tikz`, body font is Latin Modern. Figures are generated by
`make_figures.py` from committed aggregate CSVs (`reports/*.csv`, `docs/figures/empirical_atlas.csv`,
`configs/`) — **no per-patient data** is ever read.

## Conventions

The chapters are top-level `\section`s of one continuous argument; cross-references to them read as
"Chapter~N". The reusable building blocks are the callout environments (`keyresult`, `definitionbox`,
`invariantbox`, `methodsbox`, `caveatbox`, `openbox`), the scientific status pills (`\certified`,
`\provisional`, `\rejected` — these mark a finding's *evidential* standing, not project status), the
`\programstrip` pipeline diagram, and the TikZ mechanism macros. Note: status pills and TikZ contain
catcode-sensitive material and must **not** be placed inside section titles (a moving argument) — put them at
the start of the body text instead.

## Provenance

Every number is drawn from the project's committed reports (`reports/`) and the canonical Gaussian-copula
findings docs (`docs/M1_FINDINGS.md`, `docs/ADJUDICATION.md`, `docs/STRATA_OOP_FINDINGS.md`,
`docs/TEMPORAL_OOP_FINDINGS.md`, `docs/PROGNOSIS_OOP_FINDINGS.md`, `docs/TREATMENT_OOP_FINDINGS.md`, and the
synthesis `docs/COPULA_VERTICAL_FINDINGS.md`). The M2–M5 figures are regenerated from the copula result
artefacts under `results/face/{strata,temporal,prognosis,treatment}_oop/`. No per-patient data appear in the
report or its figures.
