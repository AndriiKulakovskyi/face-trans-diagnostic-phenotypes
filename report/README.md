# FACE-ATLAS — technical report (LaTeX source)

A living technical report for the FACE-ATLAS project:
**A Transdiagnostic Latent-axis Stratification of Severe Mental Illness**
(bipolar disorder · schizophrenia · depression). The document grows as each milestone is completed; this
version documents **Milestone 1 — the certified nine-dimension measurement map** and **Milestone 2 — its
stratification into a transdiagnostic continuum** (M1 + M2 complete, pending PI sign-off).

## Build

```bash
make            # regenerate figures (python3 make_figures.py) THEN build the PDF (pdflatex ×2)
make figures    # just regenerate the data-driven figures from committed aggregate CSVs
make pdf        # just build the PDF (assumes figures exist)
```

Toolchain: **pdflatex** + **python3/matplotlib** (for the figures). `faceatlas.sty` depends only on packages
in a TeX Live *basic* install (no `tcolorbox`/`titlesec`/non-standard fonts) — coloured callout boxes and all
mechanism diagrams are built from `tikz`, body font is Latin Modern. Figures are generated by
`make_figures.py` from committed aggregate CSVs (`reports/*.csv`, `docs/figures/empirical_atlas.csv`,
`configs/`) — **no per-patient data** is ever read.

## Structure

```
FACE-ATLAS.tex        main file: title page, abstract, \input of the sections
faceatlas.sty         visual system: palette, callout boxes, status pills, milestone strip, math macros,
                      and 6 TikZ mechanism diagrams (\bifactordiagram, \woodburydiagram, \observedcellgrid,
                      \discoveryflow, \structuregateflow, \archetypesimplex)
make_figures.py       generates the 10 M1 data-driven PNGs in figures/ from aggregate CSVs
                      (M2 figures m2_*.png are reused from docs/figures/, generated by scripts/2x)
references.tex        bibliography (manual thebibliography)
sections/
  01_introduction.tex   framing, four-milestone architecture, invariants, hybrid-discovery diagram
  02_data.tex           data foundation, no-imputation pipeline, observed-cell grid, coverage
  03_model.tex          candidate ontology (9 eligible), soft priors, bifactor/ESEM, mixed likelihoods
  04_estimation.tex     staged continuation, Gaussian marginal = FIML, Woodbury mechanism, compute
  05_results.tex        the NINE-dimension map, prior→posterior atlas, biology⊥G, Φ, adjudication
  06_validation.tex     confirmation, certification, robustness, invariance, dual-block PPC
  scoring.tex           per-patient coordinates + reliability tiers
  m2_strata.tex         M2: structure gate, continuum verdict, 8 archetypes, severity spine, DSM-5 head-to-head
  07_engineering.tex    repository, config-first design, tests, the two fixed bugs, reproducibility
  08_roadmap.tex        M1 complete → M2 strata → M3 temporal → M4 prognosis → M5 treatment
  09_limitations.tex    limitations and open problems
  10_appendix.tex       notation, prior atlas, acceptance gates, glossary
figures/
  prior_atlas.png       the prior (theory) loading atlas
  fig_*.png             generated: empirical atlas, prior→posterior, biology⊥G, Φ, WAIC, invariance,
                        PPC, reliability tiers, soft-prior shrinkage, coverage
```

(File-name prefixes `01..10` are cosmetic; section numbers come from `\section` order in `FACE-ATLAS.tex`,
where `scoring.tex` is `\input` between validation and engineering.)

## Extending the document for later milestones

Each milestone is a self-contained section. To add **M2 (strata)**: write `sections/11_strata.tex`, `\input`
it from `FACE-ATLAS.tex` after the roadmap, advance `\milestonestrip{2}` → `\milestonestrip{3}` on the cover
and intro, and move the M2 paragraph in `08_roadmap.tex` from `\planned` to a back-reference. The callout
environments (`keyresult`, `definitionbox`, `invariantbox`, `methodsbox`, `caveatbox`, `openbox`), the status
pills (`\certified`, `\provisional`, `\rejected`, `\planned`), and the TikZ mechanism macros are reusable.
Note: status pills and TikZ contain catcode-sensitive material and must **not** be placed inside section
titles (a moving argument) — put them at the start of the body text instead.

## Provenance

Every number is drawn from the project's committed reports (`reports/0*–13_*`), `docs/M1_FINDINGS.md`, and
`docs/ADJUDICATION.md`, and is reproducible from `scripts/01_build_data.py` → `04_fit.py` → the confirmation,
invariance, certification, robustness, scoring, and PPC scripts. No per-patient data appear in the report or
its figures.
